# Exercícios de Python - Curso em Vídeo

Este repositório contém as resoluções dos desafios propostos no curso de Python do professor Gustavo Guanabara (Mundo 1). O foco principal é consolidar os fundamentos da linguagem e a lógica de programação.

##  Conceitos Praticados:
* Tratamento de dados e aritmética básica
* Uso de módulos e bibliotecas (Math, Random)
* Manipulação de textos/strings
* Estruturas condicionais (`if/else`)

##  Tecnologias:
* Python 3
